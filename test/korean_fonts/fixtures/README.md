# Local catalog fixture

`fonts.json` is generated by the unchanged manifest generator from locally
converted KoPubBatang and upstream NotoSansExtended files. Its sizes and CRC32
values are real, not estimates. The GitHub URLs are deployment targets; this
fixture does not mean any asset has been published or can be downloaded there.

Generate the files and refresh the fixture from the repository root:

```sh
.venv/bin/python lib/EpdFont/scripts/build-sd-fonts.py \
  --only KoPubBatang,NotoSansExtended --jobs 2 \
  --output-dir build/kimchi-sd-fonts --manifest \
  --manifest-output test/korean_fonts/fixtures/fonts.json
KIMCHI_SD_FONT_FIXTURES="$PWD/build/kimchi-sd-fonts" \
  ctest --test-dir build/test -R 'KoreanFont' --output-on-failure
```

See `lib/EpdFont/builtinFonts/source/KOREAN-FONTS.md` before any public release.
